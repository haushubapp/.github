# .github

O perfil público da organização HausHub.

[`profile/README.md`](profile/README.md) é o que o GitHub renderiza em
[github.com/haushubapp](https://github.com/haushubapp) — esse caminho exato, nesse repositório com
esse nome exato, é o único lugar de onde a página da organização lê. Um repositório com o mesmo nome
da organização **não** serve para isso; esse comportamento é de conta de usuário.

Não há código aqui. Editar `profile/README.md` muda a página da organização no próximo carregamento.
